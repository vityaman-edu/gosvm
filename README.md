# GoSVM

Yet Another Go Symbolic Virtual Machine based on Alexey Menshutin course.

## Prepare

Enter the Nix development shell.

```sh
nix develop
```

I recommend using Zed editor.

```sh
zed .
```

Install precommit hooks.

```sh
pre-commit install
```

## Build & Test

```sh
pre-commit run --all-files
```
